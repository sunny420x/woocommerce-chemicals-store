# WooCommerce Chemicals Store Manager 

## ระบบนี้คืออะไร ?
<strong>WooCommerce Chemicals Store Manager</strong> คือระบบที่ออกแบบมาเพื่อช่วยจัดการโครงสร้างพื้นฐานของการขายปลีกสารเคมี 
ในเวอรชันปัจจุบันประกอบไปด้วยฟังก์ชัน ได้แก่ 
- คิดค่าขนส่งแยกกล่องสำหรับสารเคมีที่เข้ากันไม่ได้ ได้แก่ กรด เบส ออกซิไดเซอร์ และรีดิวซิงเอเจนต์

## Dependencies
ปลั้กอินนี้จำเป็นต้องใช้งานร่วมกับปลั้กอิน <strong><a href="https://github.com/sunny420x/woocommerce-advance-shipping" target="_blank">woocommerce-advance-shipping</a></strong>
เพื่อให้สามารถจัดการการจัดส่งสารเคมีได้อย่างมีประสิทธิภาพ

## วิธีการติดตั้ง
สามารถติดตั้งปลั้กอินนี้ได้โดยการดาวน์โหลดไฟล์นี้จาก Github หน้านี้ และอัพโหลดลงในหน้า /wp-admin/plugin-install.php หลังจากอัพโหลด 
และเปิดใช้งาน (Activate) ระบบจะทำการสร้างตารางและคอลัมน์ใหม่จากตารางเดิมโดยอัตโนมัติ
